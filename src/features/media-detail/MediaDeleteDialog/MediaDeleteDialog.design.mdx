# MediaDeleteDialog

## 責務
単一Mediaの削除確認を表示し、キャンセルと確定の意思決定を呼び出し元へ通知する。実際の削除処理や永続化は所有しない。

## 表示・操作契約
- 「Mediaを削除」、対象のファイル名・ラベル・タイトルを使わない確認文と復元できない旨、キャンセル・削除を表示する。
- キャンセルでは対象Mediaを変更しない。確定では対象Mediaを引数として通知する。
- MediaDetail上から起動しても確認Dialogが手前に表示される。

## テスト観点
- 削除ボタンから確認Dialogを開ける。
- キャンセル・閉じる・確定の各操作と、MediaDetailの表示状態。
- Desktop / Compact、Modal重なり順。
