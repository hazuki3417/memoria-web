# MediaDetailPreview

## 責務
選択中Mediaの画像プレビューとそのViewport操作を表示する。画像の選択順序・Viewport stateのauthoritative ownerは呼び出し元とし、一覧取得や永続化を行わない。

## 入出力と状態
- `detail`は選択中のMedia、`stateItems`は順序付きMedia一覧、`prev`・`next`は移動可能な隣接Media。
- `setDetail`で選択変更を通知し、移動前に`prepareNavigation`を呼ぶ。`closeMediaDetail`で閉じる。
- `detailZoom`、`detailRotate`、`detailRotateAnimated`、`detailDirection`は渡されたViewport stateを表示・更新する。
- `detailInfoOpened`と`setDetailInfoOpened`で情報パネル開閉を通知し、`compact`で操作配置を切り替える。

## 表示・操作契約
- 画像、表示失敗時の代替表示、前後移動ボタン、回転・ズーム操作、情報パネル開閉ボタンを保持する。
- 先頭・末尾に存在しない方向への移動ボタンは表示しない。画像番号は渡された一覧順を基準に表示する。
- Desktop / Compactで既存の操作配置、画像の拡大縮小、アニメーション、余白を維持する。

## Story / テスト観点
- 縦長・横長・画像失敗、先頭・中間・末尾の操作可否、番号表示。
- ズーム境界、回転、移動時のViewport初期化、情報パネル開閉。
- Desktop / CompactのVisual / Behavioral / Responsive Regression。
