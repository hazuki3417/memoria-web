# TagsEditDialog

## 責務
画像のTagの追加・除外と確定・キャンセルを担当する。画像詳細全体の選択画像、一覧、Viewport、永続化は所有しない。

## 入出力と状態
- Modalの表示条件、編集中の値、確定・キャンセルCallbackは呼び出し元が所有する。
- このComponentは受け取った状態を表示し、利用者の操作をCallbackで通知する。
- 他の編集Dialogの状態や画像詳細全体の状態を所有しない。

## 表示・操作契約
- 呼び出し元の編集Draftを表示する。確定はDraftを反映し、キャンセルは保存しない。表示条件と編集状態は呼び出し元が所有する。
- 既存MediaBrowserのタイトル、説明、入力候補、ボタン、ModalのzIndex・重なり順、キーボード操作、Responsive Behaviorを維持する。

## Story / テスト観点
- 追加・除外、空状態、確定、キャンセル、再オープン時の値。
- 開いた状態と閉じた状態、操作時のCallback、Desktop / Compact、画像詳細Modalとの重なり順。
- 変更前のMediaBrowserと比較した表示・操作回帰。
