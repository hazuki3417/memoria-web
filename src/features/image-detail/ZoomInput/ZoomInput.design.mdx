# ZoomInput

## 責務

50〜300%の倍率入力と候補選択を担当。数値の範囲制限と入力確定を検証する。

## 表示・操作契約

- 既存MediaBrowser / GroupBrowserからの表示内容、操作、状態、レスポンシブ動作を維持する。
- 状態の所有・受け渡しを明示し、consumer固有のデータ接続を混入させない。

## Story / テスト観点

- 基本表示と閉じる操作
- 関連する状態変更、操作、表示差分
- Desktop / Compactの表示（対象となる場合）

現段階は段階的抽出中であり、動作・Visual Regressionの確認は未完了。
