# ZoomInput

## 責務
画像詳細の倍率を表示し、50〜300%の範囲で入力・候補選択を受け付ける。画像自体の変形や倍率Stateの所有は行わない。

## 入出力と状態
- `value` は呼び出し元が所有する現在倍率、`onChange` は確定した倍率を通知する。
- 数値入力と候補選択の両方で倍率を変更できる。範囲外の入力、空文字、編集中の値と確定値の扱いは実装と照合して検証する。
- このComponent自体に閉じる操作はない。Modalの開閉は所有しない。

## 表示・操作契約
- 倍率の単位（%）、選択候補、フォーカス・キーボード操作を既存実装から維持する。
- 親のViewportによる拡大・縮小・リセット操作と整合する。

## Story / テスト観点
- 100%と200%の表示、候補選択、手入力、境界値50%・300%。
- 範囲外、空入力、キーボード確定・フォーカス離脱、`onChange` の呼び出しを検証する。
- 親から`value`が更新されたときの表示同期を検証する。

## 検証状態
Storyは基本倍率の表示のみ。入力操作・境界値・回帰テストは未検証。
