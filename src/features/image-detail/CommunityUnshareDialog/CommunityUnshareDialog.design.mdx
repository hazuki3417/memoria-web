# CommunityUnshareDialog

## 責務

共有解除の確認とキャンセルを扱う。画像詳細の編集フローのうち、このModalのみを所有する。

## 表示・操作契約

- 共有解除は赤い危険操作、対象Community名を表示する。
- 既存のタイトル、説明、選択肢、zIndex、キャンセル・確定動作を維持する。
- 表示条件と編集状態は呼び出し元が所有する。

## Story / テスト観点

- 開いた状態の表示と閉じた状態
- 入力・選択、確定、キャンセル
- 無効状態や対象データの表示（該当する場合）

現段階ではUI移設中のため、保存は既存のモック動作を維持する。
