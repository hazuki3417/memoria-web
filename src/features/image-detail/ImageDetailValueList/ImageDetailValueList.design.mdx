# ImageDetailValueList

## 責務
GroupsとTagsの双方に共通するBadge値一覧と多件数時の展開表示を提供する。Groups/Tagsの意味、見出し、編集操作は所有しない。

## 入出力と状態
- `values`は表示する文字列配列、`variant`はBadgeの外観。
- `expanded`は外部から受け取る展開状態、`onToggle`は状態変更の通知。

## 表示・操作契約
- 0件は「未設定」、1〜6件は全件、7件以上は先頭6件と展開ボタンを表示する。
- 残りの値は200msのCollapseで開閉する。ボタンのラベル、件数、`aria-expanded`、アイコン回転を維持する。
- Badgeの折り返しと余白を維持し、親固有の見出しや区切り線を描画しない。

## Story / テスト観点
- 0件、6件、7件以上、展開/折りたたみ、outline/light、長い値。
