# ImageDetailClassificationSection

## 責務
画像に付与されたGroupsまたはTagsの件数・値を表示し、編集入口と多件数時の展開操作を提供する。編集Dialogと値の永続化は所有しない。

## 入出力と状態
- `kind`は`groups`または`tags`。表示値は`detailValues[kind]`を使用する。
- `detailSectionsExpanded[kind]`を展開状態として受け取り、`toggleDetailSection(kind)`で変更を通知する。
- 編集操作は`openDetailEditor(kind)`で通知する。

## 表示・操作契約
- Groupsはoutline Badge、Tagsはlight Badgeを用いる。0件なら「未設定」を表示する。
- 先頭6件を常時表示し、7件以上では残りをCollapseで展開する。展開操作のラベル、件数、200msのアニメーションを維持する。
- Groupsの後だけ区切り線を表示し、Tagsの後は親Panelが区切り線を表示する。

## Story / テスト観点
- Groups / Tags、0件・6件・7件以上、長い値の折り返し。
- 編集通知、展開通知、`aria-expanded`、Badge variantと区切り線。
