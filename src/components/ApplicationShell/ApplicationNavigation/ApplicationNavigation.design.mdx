# ApplicationNavigation

## Overview
Application Shellのヘッダー下に表示する、コンテキスト内ナビゲーション用Drawer。Personal/Communityのメニュー構成自体は外部が決める。

## Responsibilities
- **所有する**: Drawerの開閉表示、ヘッダーとの位置関係、overlay、閉じる操作、項目選択後の閉じる通知。
- **所有しない**: メニュー項目の生成・並び・権限、ルーティング、コンテキストの切り替え、項目の内部表示。内容表示はApplicationNavigationContentに委譲する。

## Design Decisions
- 既存Application Shellの40pxヘッダーを覆わず、Drawerとoverlayをその下から表示する。
- Drawerとメニュー内容を分離する。内容の表示・スクロール・フッターをDrawerの開閉に依存させず検証するため。
- 既存UIとの互換性を維持するため、Drawer幅248px、overlay opacity 0.35、影、Escape/外側クリックで閉じる設定を保持する。

## Component Contract
- `opened`と`onClose`は親が管理する開閉状態の契約。
- 項目選択時は`onSelect(itemId)`を呼び、続けて`onClose()`を呼ぶ。遷移や状態更新は行わない。
- `items`と`accentColor`は内容Componentにそのまま渡す。
- Drawer高さは`calc(100dvh - 40px)`。スクロールは内容領域内で行い、フッターを末尾に維持する。

## Test Design
- Storyで既存のOpened / CommunityAccentの見た目を維持し、Drawer位置・overlay・フッターをVRTで確認する。
- Interactionでは選択時の通知順序、Escape/外側クリック時の閉じる通知を検証する。Mantine自身の内部動作を重複テストしない。
- メニュー項目の詳細表示とスクロールの境界値はApplicationNavigationContent側で検証する。
