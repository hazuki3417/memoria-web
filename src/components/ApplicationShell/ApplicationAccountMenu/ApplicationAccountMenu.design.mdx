# ApplicationAccountMenu

## Overview
ユーザーと現在のContextを表示し、設定・ログアウト操作を提供する。

## Responsibilities
- **所有する**: Avatar、表示名、Context名、Menuの表示、操作callbackの通知。
- **所有しない**: ユーザー情報の取得、設定画面への遷移、ログアウト処理の実行。

## Design Decisions
- 既存のUI、文言、操作、Responsive Behaviorを維持したままComponent Directoryへ移動する。
- Feature / Application Shellの公開APIはroot `index.ts`、Component単位の公開入口は同Directoryの`index.ts`が担当する。

## Component Contract
- 既存のcompact button、avatar size、Menu位置、設定・ログアウトの順序と文言を維持する。

## Test Design
- Default / WithAvatarLabelの表示とMenuの開閉、設定・ログアウトcallbackを確認する。
