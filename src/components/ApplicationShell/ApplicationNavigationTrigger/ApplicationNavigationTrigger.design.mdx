# ApplicationNavigationTrigger

## Overview
Application ShellのナビゲーションDrawerを開閉するBurgerボタン。

## Responsibilities
- **所有する**: Burgerの表示、開閉状態のARIA表現、トグル通知、hidden時の表示と操作抑制。
- **所有しない**: Drawerの表示・開閉状態の保持、画面幅に応じたhidden判定。

## Design Decisions
- hidden時も`visibility: hidden`で配置領域を維持し、ヘッダーの既存レイアウトを変えない。
- hidden時はdisabled、tabIndex -1、aria-hiddenを設定して操作・フォーカスから外す。

## Component Contract
- `opened`をBurgerと`aria-expanded`に反映する。
- 操作時は`onToggle`を通知する。状態更新は親の責務。
- `aria-controls`はApplicationNavigationContentの`application-context-navigation`を指す。

## Test Design
- opened/closed/hiddenの表示とARIA、hidden時の操作不可を確認する。
- 親のレスポンシブ判定やDrawerの開閉はこのComponentでは検証しない。
